# Student Management System

A simple Student Management System built using Python, Tkinter, and SQLite.

## Features

- Add and manage student records
- Store student roll numbers, names, and marks
- Validate student data
- Save records in an SQLite database
- Export student records to CSV
- User-friendly graphical interface

## Technologies Used

- Python
- Tkinter
- SQLite
- CSV Module

## Project Files

- `main.py` — Main application code
- `students.db` — SQLite database, created when the application runs
- `README.md` — Project documentation
- `.gitignore` — Files excluded from Git tracking

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

   `python main.py`

5. Use the application to manage student records and export data to CSV.

## CSV Export

The application can export student records into a CSV file that can be opened in Microsoft Excel or other spreadsheet applications.

## Learning Goals

This project demonstrates Python functions, GUI development, database operations, input validation, and CSV file handling.
